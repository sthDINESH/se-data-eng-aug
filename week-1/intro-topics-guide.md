# Introduction topics review

Guidance in fundamental topics/tools/concepts important to understand and be confident with during the 3 weeks course.

## How to learn concept in a simple way

"Keep it stupid-simple"

1. WHAT?
2. HOW?
3. WHY?

## SQL

Standard Query Language 
Programming language to communicate with relational databases.

Allows the user to ask questions of the database.

All about:
- Structure
- Relationships
- Transactions

** HOW? **
- Tables
    - Usually entities
- Primary and Foreign Keys
    - Denote links between tables
    - Avoiding duplication
- SQL keywords etc to scan data in the tables


** WHY? **
- Structure 
    - Easy to audit
- Relationships
- Transactions
- Easy to read
- Industry standard
- Most business data is relational
- Efficient

## Python

High level programming language that is designed for readability(similar to English) and prebuilt code libraries.

** HOW? **
- variables
- Collections
    - Lists
    - Tuples
    - Dictionaries
    - etc.
- Functions
- Loops(iteration)
    - for
    - while
- Conditional logic
- Classes
- Modules
- Libraries

** Why? **
- Readable/Easy to understand
- Lots of libraries etc.
- Diverse
    - Useful across teams/projects/scenarios
- Works with many other systems/languages
    -Eg. APIs, SDKs etc.
- Open source
- Good for automation/scripting
- Versatile+Very popular
