## git vs github

Git and GitHub are related, but they are not the same thing.

Git is a version control system.

- It tracks changes in files over time.
- It lets multiple people work on the same project without overwriting each other.
- It keeps a history of commits and allows branching and merging.

GitHub is a hosting platform for Git repositories.

- It stores Git projects online.
- It adds collaboration features like pull requests, issues, code review, CI/CD, and project management.
